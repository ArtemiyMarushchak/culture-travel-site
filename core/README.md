# core/ — ядро сайта

| Файл / папка | Назначение |
|--------------|------------|
| `build.mjs` | Сборщик → `dist/` *(пока: `../tools/build.mjs`)* |
| `init.js` | Запуск JS на странице |
| `registry.js` | Инициализаторы блоков |
| `anchors.js` | Якорные ссылки |
| `video-overlay.js` | Hero-видео при скролле |
| `site.json` | Контакты, домен, юр. данные |
| `nav.json` | Меню |
| `blocks.registry.json` | Каталог блоков |
| `layouts/default.html` | HTML-оболочка *(пока: `../layouts/`)* |

Полная карта: `docs/СТРУКТУРА.md`
