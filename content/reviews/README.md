# Отзывы на главной

Редактируйте `content/reviews/catalog.json`.

## Вкладка «Отзывы гостей» (основная)

Добавляйте объекты в `items`:

```json
{
  "text": "Текст отзыва",
  "author": "Имя или «Постоянный клиент»",
  "meta": "Южная Африка, 2026"
}
```

Пришлите тексты — вставляем сюда и пересобираем сайт.

## Вкладка «Яндекс» (дополнительно)

Ссылку на отзывы в Яндекс.Картах — в `platforms.yandex.reviewUrl` или `core/site.json` → `reviews.yandexUrl`.

Виджет Яндекса — в `#yandex-reviews-widget` на вкладке «Яндекс».

Google не используем.
