# blocks-secondary/ — второстепенные страницы

HTML + CSS + JS для страниц **кроме** секций главной.

| Папка | Страница / назначение |
|-------|------------------------|
| `brochure/` | Бизнес-авиация, Круизы |
| `hotel-catalog/` | Отели |
| `news-list/` | Список новостей |
| `news-layout/` | Одна новость (шаблон) |
| `case-layout/` | Один кейс (шаблон) |
| `legal-page/` | Политика данных |
| `error-404/` | 404 |
| `modal/` | Попапы |
| `contact-card/` | Онлайн-визитка → `/contact/` |

Тексты кейсов и новостей — в `pages/data/cases/` и `pages/data/news/`, не здесь.
