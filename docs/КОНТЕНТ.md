# Контент: один файл → всё появляется само

## Главное правило

**Создал один JSON** → build автоматически:

1. **Карточка** в списке (`/news/`, `/hotels/`, слайдер на главной)
2. **Отдельная SEO-страница** (`/news/slug/`, `/hotels/slug/`, `/cases/slug/`)
3. **Header + Footer** на каждой странице (не пишешь руками)

Настройки типов: `core/content-types.json`

---

## Header и Footer — везде автоматически

Файл: **`core/page-layout.json`**

```json
{
  "before": [{ "type": "header" }],
  "after": [{ "type": "footer" }, { "type": "modal" }]
}
```

В `pages/*.page.json` пишешь **только середину** страницы:

```json
{
  "slug": "/news/",
  "blocks": [
    { "type": "news-list" }
  ]
}
```

Build сам собирает: `header → news-list → footer → modal`

**Исключение:** визитка `/contact/` — `"layout": "minimal"` (без header/footer)

## Новость — пошагово

### 1. Скопируй шаблон

```
content/news/_template.json  →  content/news/2026-safari-season.json
```

### 2. Заполни поля

```json
{
  "slug": "2026-safari-season",
  "title": "Заголовок",
  "date": "2026-03-01",
  "cover": "/assets/images/news/cover.webp",
  "excerpt": "Анонс для карточки",
  "body": "<p>Текст новости</p>",
  "seo": {
    "title": "Заголовок | Culture Travel",
    "description": "Meta description"
  }
}
```

### 3. Сборка

```bash
node tools/build.mjs
```

### 4. Результат

| Что | URL |
|-----|-----|
| Карточка в списке | `/news/` |
| Полная страница | `/news/2026-safari-season/` |
| Header + Footer | на обеих |

## Кейс — то же самое

```
content/cases/_template.json  →  content/cases/maldives.json
```

```json
{
  "slug": "maldives",
  "title": "Мальдивы",
  "featured": true,
  ...
}
```

| Что | Где |
|-----|-----|
| Карточка на главной | слайдер кейсов (если `"featured": true`) |
| Полная страница | `/cases/maldives/` |

---

## Отель — то же самое

```
content/hotels/_template.json  →  content/hotels/four-seasons.json
```

| Что | Где |
|-----|-----|
| Карточка в каталоге | `/hotels/` |
| Кнопка «Подробнее» | → `/hotels/four-seasons/` |
| Модалка «Фото и видео» | на карточке в каталоге |

## Схема связи

```
content/news/my-article.json
         │
         ├──► /news/              (карточка в news-list)
         │
         └──► /news/my-article/    (страница news-layout)
                    │
                    └── header + footer (page-layout.json)
```

```
content/cases/my-case.json
         │
         ├──► /  (слайдер, если featured)
         │
         └──► /cases/my-case/  (case-layout)
```

```
content/hotels/my-hotel.json
         │
         ├──► /hotels/  (карточка в hotel-catalog)
         │
         └──► /hotels/my-hotel/  (hotel-layout)
```

## Обычная страница (не контент)

Файл `pages/cruises.page.json` — только блоки середины:

```json
{
  "slug": "/cruises/",
  "blocks": [
    { "type": "brochure", "data": { ... } }
  ]
}
```

Header/footer добавятся сами.

---

## Для нейросети

1. Открыть `_template.json` нужного типа
2. Сгенерировать новый файл с уникальным `slug`
3. Положить в `content/news/` или `cases/` или `hotels/`
4. Запустить build

Никакой отдельной «привязки» вручную не нужно — **slug в JSON = URL страницы**.
