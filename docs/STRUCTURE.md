# Структура репозитория

Подробная карта папок. Для быстрой навигации см. также корневой [README](../README.md).

---

## Дерево верхнего уровня

```
culture-travel-site/
├── content/              Контент (данные)
├── assets/               Медиа
├── pages/                Страницы (маршруты)
├── blocks/               Основные UI-блоки
├── blocks-secondary/     Вторичные блоки
├── core/                 Настройки сайта, меню, реестры
├── styles/               CSS
├── layouts/              Оболочки HTML-страниц
├── templates/            Шаблоны сборщика
├── seo/                  SEO-шаблоны и defaults
├── tools/                Сборка и preview
├── scripts/              Вспомогательные скрипты
├── docs/                 Эта документация
├── .github/workflows/    Деплой на GitHub Pages
├── dist/                 Результат сборки (генерируется)
├── package.json          npm-скрипты
├── LICENSE               Лицензия (все права защищены)
└── README.md             Навигация + лицензия
```

---

## `content/` — что видит посетитель (тексты)

| Путь | Роль |
|------|------|
| `reviews/catalog.json` | Все отзывы на главной |
| `news/*.json` | Одна новость = один файл → `/news/{slug}/` |
| `news/_template.json` | Шаблон новой новости (не публикуется) |
| `cases-slider/catalog.json` | Карточки слайдера «Мои кейсы» |
| `cases/*.json` | SEO-страница кейса |
| `cases/{slug}/tour.html` | Публичная программа тура |
| `cases/{slug}/program-full.html` | Полная программа (закрытая ссылка) |
| `hotels/*.json` | Отели (`_…` в имени = черновик) |
| `services/catalog.json` | Услуги на главной |

Правило: правите **данные**, не вёрстку блоков. Подробно: [ADMIN.md](ADMIN.md).

## `assets/` — медиа

| Путь | Роль |
|------|------|
| `images/hero/` | Постер видео-героя |
| `images/about/` | Фото в блоке / модалке «Обо мне» |
| `images/news/` | Обложки новостей |
| `images/cases/` | Кейсы и дни программ |
| `images/services/` | Услуги (широкий + квадрат `-sq`) |
| `images/hotels/` | Отели |
| `images/reviews/` | Опциональные фото к отзывам |
| `images/flags/` | Флаги стран (SVG, ISO) |
| `images/og/` | Картинка для соцсетей |
| `icons/` | Логотипы и favicon |
| `videos/` | Hero MP4 |
| `fonts/montserrat/` | Локальный шрифт Montserrat (woff2) |

Правила форматов: [ASSETS.md](ASSETS.md).

---

## `pages/` — страницы

Файлы `*.page.json` описывают:
- URL / slug;
- title, description, robots;
- какие блоки подключать.

Примеры: главная, заглушки круизов/отелей/туров, 404, закрытая программа.

---

## `blocks/` и `blocks-secondary/`

Вёрстка секций: шапка, герой, отзывы, модалки, футер и т.д.  
Обычно **не трогать**, если задача — контент.

Каждый блок: `*.html` + `*.css` + иногда `*.js`.  
Реестр для сборки: `core/blocks.registry.json`.

---

## `core/` — «пульт» сайта

| Файл | Зачем |
|------|--------|
| `site.json` | Название, URL, телефон, email, Telegram, реквизиты, SEO-дефолты |
| `nav.json` | Пункты меню шапки |
| `page-layout.json` | Что на каждой странице: шапка + подвал + модалки |
| `blocks.registry.json` | Список блоков для CSS/JS |
| `content-types.json` | Типы контента |
| `anchors.js` | Якоря главной + drawer «Обо мне» |
| `i18n.js` / словари | Подписи интерфейса |

---

## `styles/`

- Токены (цвета, отступы, типографика).
- UI-компоненты (кнопки, крошки…).
- `main.css` собирает всё воедино; блоки подключаются через реестр.

---

## `tools/`

| Скрипт | Назначение |
|--------|------------|
| `build.mjs` | Полная сборка → `dist/` |
| `preview.mjs` | Локальный HTTP-сервер для `dist/` |

См. [BUILD.md](BUILD.md).

---

## `seo/`

Шаблоны и defaults для:
- `robots.txt`
- `sitemap.xml`
- `llms.txt`
- мета-тегов по умолчанию

См. [SEO.md](SEO.md).

---

## `dist/` — только результат

Сюда пишет сборщик готовый сайт.  
На GitHub Pages уходит содержимое именно этой папки.  
**Ручные правки в `dist/` бессмысленны** — следующий `build` их сотрёт.
