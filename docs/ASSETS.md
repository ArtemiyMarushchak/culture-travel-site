Правила для `assets/`. Соблюдайте — иначе тяжёлые страницы и битые картинки.

Только локальные файлы из этого репозитория.

## Формат файлов

| Тип | Формат | Зачем |
|-----|--------|--------|
| Фото контента | **JPEG (`.jpg`)** или **WebP (`.webp`)** | Быстрая загрузка |
| Флаги | **SVG** | Чёткость в любом размере |
| Лого / favicon | **SVG** | Масштаб без потери |
| Видео героя | **MP4** (H.264), без звука | Фон; на сайте muted |

Рабочий файл: `assets/videos/hero.mp4`.  
Исходник высокого битрейта (если есть): `assets/videos/hero.source.mp4` — **не обязателен на проде**, можно держать локально/в архиве.

Золотая середина (качество на фоне с оверлеем ≈ HD, вес меньше):

```bash
ffmpeg -i assets/videos/hero.source.mp4 -an \
  -vf "scale=1600:-2:flags=lanczos" \
  -c:v libx264 -preset medium -crf 23 -pix_fmt yuv420p \
  -movflags +faststart assets/videos/hero.mp4
```

- **1600×900** — на hero с затемнением глаз почти не отличит от 1080p  
- **CRF 23** — стандарт x264 «без видимой потери»  
- **без звука** — на сайте видео muted  
Не используйте CRF 18–20 для уже сжатого исходника: файл может стать *тяжелее*. Постер: `assets/images/hero/poster.jpg`.
| Прозрачность / UI | SVG или PNG (редко) | Только если нужен альфа-канал |

**Не использовать на проде:** огромные PNG-фото, BMP, TIFF, необрезанные 10+ МБ кадры.

Рекомендуемый вес одного фото: **до 300–500 KB** (обложки), дни программы — **до 200–400 KB**.  
Ширина по длинной стороне: обложки **1600–2400 px**, квадраты услуг **1600×1600**, дни тура **1200–1800 px**.

WebP предпочтителен для новых файлов; JPEG — безопасный стандарт.  
AVIF уже есть в днях программы ЮАР — оставлять можно (лёгкий формат), новые кадры лучше **JPG или WebP**.

Сейчас тяжёлые PNG контент-фото убраны; OG: `assets/images/og/default.webp`.

## Именование

- Латиница, без пробелов: `day-03-hotel.jpg`, `yuar-programma-2026.jpg`
- Услуги: `vip-transfer.jpg` + `vip-transfer-sq.jpg` (десктоп 16∶9 / мобилка 1∶1)
- Флаги: код страны в нижнем регистре `za.svg` (ISO 3166-1 alpha-2)

## Как подключить

1. Положите файл в нужную папку.
2. Пропишите путь в JSON или HTML: `/assets/images/...`
3. `node tools/build.mjs` (или push в `main`).

Отзывы с флагом: в `content/reviews/catalog.json` поле `"country": "za"` → подставится `flags/za.svg`.  
Нет кода — будет нейтральная иконка. Все SVG флагов уже в `assets/images/flags/`.
