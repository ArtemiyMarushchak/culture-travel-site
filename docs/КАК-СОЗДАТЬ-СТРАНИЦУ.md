# Как создать новость или кейс с ЧПУ и SEO

## Короткий ответ

**Папку создавать не нужно.**  
Создаёшь **один JSON-файл** — build сам делает красивый URL и SEO-страницу.

---

## Новость — 3 шага

### Шаг 1. Скопируй шаблон

```
content/news/_template.json
        ↓
content/news/kenya-safari-2026.json
```

Имя файла — для себя (можно любое).  
**URL сайта** задаёт поле `"slug"` внутри файла.

### Шаг 2. Заполни JSON

```json
{
  "slug": "kenya-safari-2026",
  "title": "Сезон сафари в Кении открыт",
  "date": "2026-08-10",
  "cover": "/assets/images/news/kenya.webp",
  "excerpt": "Короткий анонс для карточки в списке.",
  "body": "<p>Полный текст новости. Можно HTML.</p>",
  "seo": {
    "title": "Сезон сафари в Кении | Culture Travel",
    "description": "VIP-сафари в Кении — индивидуальные маршруты от Culture Travel."
  }
}
```

### Шаг 3. Сборка

```bash
python3 tools/build.py
```

---

## Что получится автоматически

| Что | URL |
|-----|-----|
| Карточка в списке | `http://127.0.0.1:8766/news/` |
| **ЧПУ-страница** | `http://127.0.0.1:8766/news/kenya-safari-2026/` |
| На проде | `https://culture-travel.ru/news/kenya-safari-2026/` |

**ЧПУ** = поле `"slug": "kenya-safari-2026"` → человекочитаемый URL без `?id=123`.

---

## Кейс — то же самое

```
content/cases/_template.json
        ↓
content/cases/maldives-private-villa.json
```

```json
{
  "slug": "maldives-private-villa",
  "title": "Private Villa — Мальдивы",
  "featured": true,
  "seo": {
    "title": "Private Villa Maldives | Culture Travel",
    "description": "..."
  }
}
```

| Что | URL |
|-----|-----|
| Слайдер на главной | `/` (если `"featured": true`) |
| Страница кейса | `/cases/maldives-private-villa/` |

---

## SEO — откуда берётся

Build сам подставляет в `<head>`:

- `<title>` из `seo.title`
- `<meta description>` из `seo.description`
- `canonical` URL
- Open Graph (og:title, og:description, og:image)
- JSON-LD (`NewsArticle` / `Article`)
- запись в `sitemap.xml`

**Тебе не нужно** создавать HTML или папку `news/kenya-safari-2026/` — build создаёт `dist/news/kenya-safari-2026/index.html` сам.

---

## Что НЕ нужно делать

| ❌ | ✅ |
|----|-----|
| Создавать папку для каждой новости | Один `.json` файл |
| Прописывать ссылку вручную | slug в JSON = URL |
| Добавлять header/footer | Автоматически из `core/page-layout.json` |
| Писать HTML страницы | Шаблон `news-layout` уже есть |

---

## Правила для slug (ЧПУ)

- латиница, через дефис: `kenya-safari-2026`
- без пробелов, без кириллицы
- коротко и понятно для Google

Плохо: `новость1.json`, slug `"123"`  
Хорошо: `kenya-safari-2026.json`, slug `"kenya-safari-2026"`
