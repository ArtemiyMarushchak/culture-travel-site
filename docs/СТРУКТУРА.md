# Папки проекта

```
assets/           медиа + Montserrat (docs/ASSETS.md)
blocks/           блоки главной и общие
blocks-secondary/ внутренние (программа тура, визитка)
content/          JSON и HTML контента (docs/ADMIN.md)
core/             site.json, nav, registry, boot/init
docs/             документация
layouts/          каркас HTML
pages/            страницы (*.page.json)
seo/              head + schema defaults
styles/           CSS: tokens → foundation → ui → blocks
templates/        шаблоны case/news/hotel
tools/            build.mjs, preview.mjs
dist/             сборка (не редактировать)
```

Сборка: `content` + `pages` + `blocks` → `tools/build.mjs` → `dist/`.  
CSS в браузере: один вход `styles/main.css`.
