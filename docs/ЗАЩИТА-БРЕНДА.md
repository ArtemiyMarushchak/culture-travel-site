# Защита бренда — если код или сайт скопировали

## Главное — без паники

**Да, теоретически человек может скопировать сайт** и выложить на другом домене.

Но важно понимать:

| Миф | Реальность |
|-----|------------|
| «Приватный репо = никто не скопирует» | **Нет.** Любой посетитель скачивает HTML/CSS/JS/картинки с живого сайта — репо тут не при чём |
| «Публичный GitHub = все украдут бренд» | Код виден, но **официальный** сайт определяется **доменом**, **доверием** и **юридически** |
| «Можно защититься только технически» | **Нет.** Для бренда главное — **домен + право + привычка клиентов** |

Копировать статику может кто угодно — так устроен интернет. Задача — чтобы клиент **никогда не путал** подделку с вами.

## Что реально защищает (по силе)

### 1. Официальный домен — culture-travel.ru ✅

Это ваш главный «паспорт» в сети.

- Подключите **culture-travel.ru** к GitHub Pages или своему серверу
- Всегда **HTTPS** (замок в браузере)
- В рекламе, визитках, Telegram — **только этот домен**

Клиент привыкает: настоящая «Культура Путешествий» = **culture-travel.ru**.

Подделка на `culture-travel-copy.ru` или `github.io/чужой-логин` — **другой адрес**, не вы.

### 2. Один канал связи — Telegram / телефон ✅

В `core/site.json` — ваши официальные контакты. Везде одинаково:

- Telegram: **@baglay_anna** (или как в site.json)
- Телефон с сайта
- Email с домена (лучше `...@culture-travel.ru`, когда будет почта на домене)

**Правило для клиентов:** «Связаться можно только через сайт culture-travel.ru или проверенный Telegram из footer».

Мошенник может скопировать дизайн, но **не может** скопировать ваш Telegram-аккаунт или ваш номер на другом домене без подмены — клиент сверяет.

### 3. Товарный знак и авторское право ⚖️

| Что | Зачем |
|-----|--------|
| **Товарный знак** «Культура Путешествий» (Роспатент) | Запретить чужим использовать имя в той же сфере (туризм) |
| **Авторское право** на тексты, фото, видео, логотип | Требовать снятия копии с хостинга |
| Строка в README: *Proprietary* | Фиксирует, что код не «свободный для копирования» |

Регистрация ТЗ — не срочно на старте, но для люкс-бренда **имеет смысл** (консультация с патентным поверенным).

### 4. Поисковики — только ваш сайт в топе 🔍

После запуска домена:

- **Google Search Console** — подтвердить culture-travel.ru
- **Яндекс.Вебмастер** — то же
- Sitemap уже генерируется сборкой (`sitemap.xml`)

Официальный сайт индексируется первым; подделки часто не продвигаются, если вы не даёте им ссылки.

### 5. Canonical URL (уже в проекте)

В каждой странице — `<link rel="canonical" href="https://culture-travel.ru/...">`.

Поисковик понимает: **оригинал** — ваш домен, не копия.

### 6. JSON-LD Organization (можно добавить позже)

Схема «организация» с официальным URL, названием, контактами — ещё один сигнал для Google «это мы».

## Если нашли подделку — что делать

### Шаг 1 — зафиксировать

- URL подделки
- Скриншоты (Wayback Machine: https://web.archive.org)
- Дата обнаружения

### Шаг 2 — жалоба хостингу

| Где висит копия | Куда писать |
|-----------------|-------------|
| GitHub Pages (`*.github.io`) | GitHub DMCA: https://github.com/contact/dmca |
| Другой хостинг | Abuse email регистратора домена (whois) |
| Cloudflare / Netlify | Их форма abuse / DMCA |

Текст: нарушение авторских прав (дизайн, тексты, фото, логотип) и/или товарного знака.

### Шаг 3 — поисковики

- Google: удаление страницы из выдачи (Search Console → Removals)
- Яндекс: форма обратной связи по нарушению прав

### Шаг 4 — если обманывают клиентов

- Обращение в правоохранительные органы (мошенничество)
- Пост в официальном Telegram: «остерегайтесь подделок, только culture-travel.ru»

## Похожие домены (typosquatting)

Мошенники иногда регистрируют:

- `culture-travel.com` / `.net`
- `kultura-puteshestviy.ru`
- `culture-travel.ru.com`

**Вы не обязаны** покупать все варианты. Достаточно:

1. Ваш **.ru** основной
2. Клиентам объяснять: смотрите адресную строку
3. При росте бренда — купить 1–2 очевидных домена-защиты

## Что НЕ поможет

| Метод | Почему |
|-------|--------|
| Приватный репо вместо public | Сайт всё равно отдаёт файлы браузеру |
| «Зашифровать» HTML/CSS | Браузер должен прочитать — значит, скопировать можно |
| Убрать код с GitHub | Копируют с **живого** сайта через «Сохранить как» / wget |
| CSP на вашем сайте | Защищает **ваш** сайт от взлома, не чужие копии |

## Итог для владельца

Публичный репозиторий **не делает вас слабее** — подделать можно и без GitHub, просто сохранив страницу из браузера.

Ваша сила:

1. **Официальный домен**, который знают клиенты  
2. **Проверенные контакты** (Telegram, телефон)  
3. **Право** требовать снятия копий  
4. **SEO** — вы в поиске первые  

Код «украсть» могут. **Бренд и доверие клиентов** — только если они сами перейдут на чужой сайт без проверки. Обучите клиентов: «только culture-travel.ru».
