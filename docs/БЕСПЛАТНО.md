# Бесплатный хостинг — только домен платный

Цель: **0 ₽** за хостинг, CI, CDN. Платим только за **домен** culture-travel.ru.

---

## Вариант 1 — GitHub public + GitHub Pages ✅ проще всего

| | |
|---|---|
| Репозиторий | **Public** (код виден всем — для сайта это нормально, контент всё равно публичный) |
| GitHub | Free |
| GitHub Pages | Free |
| Actions (сборка) | Free (2000 мин/мес — хватит с запасом) |
| Private repo + Pages | ❌ нужен GitHub Pro ($4/мес) — **не берём** |

**Как работает:** push в `main` → Actions собирает `dist/` → сайт на `username.github.io` или на своём домене.

## Видео в GitHub — лимиты и риски

| Ограничение | Значение |
|-------------|----------|
| Макс. размер **одного файла** | 100 МБ (жёстко) |
| Рекомендуемый размер repo | до ~1 ГБ |
| Git LFS (free) | 1 ГБ хранилища + **1 ГБ трафика/мес** — для hero-видео может **быстро кончиться** |

### Практика для твоего hero.mp4

1. Сжать до **15–40 МБ** (H.264, 1080p или 720p, без звука если не нужен)
2. Положить **`assets/videos/hero.mp4`** — **без LFS**, обычный git
3. GitHub Pages раздаёт как статику — для старта трафика хватит
4. Если посещаемость вырастет — позже Cloudflare CDN (всё ещё free)

**Kinescope** был удобен, но зависимость от чужого сервиса. Свой mp4 = полный контроль, бесплатно.
