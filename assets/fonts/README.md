# Шрифты — Culture Travel

## Manrope (активно)

Подключение **локально** — `assets/fonts/manrope/fonts.local.css`, импорт из `styles/foundation/fonts.css`.

| Weight | Файл | Где на сайте |
|--------|------|--------------|
| **400** Regular | `manrope-regular.woff2` | body, длинный текст |
| **500** Medium | `manrope-medium.woff2` | overline |
| **600** SemiBold | `manrope-semibold.woff2` | заголовки, nav, кнопки |

Подмножества: **Latin + Cyrillic** (один файл на weight).

CDN-запас: `assets/fonts/manrope/fonts.cdn.css`.

Montserrat остаётся в `assets/fonts/montserrat/` как архив, на сайт больше не подключается.
