# Локальные assets — всё на GitHub, без Tilda

| Папка | Что |
|-------|-----|
| `assets/icons/` | логотипы, favicon, concierge |
| `assets/images/` | фото |
| `assets/videos/` | hero.mp4 |
| `assets/fonts/montserrat/` | Montserrat woff2 |

**Никаких ссылок на tildacdn.com** — когда Tilda удалится, сайт не сломается.

## Hero-видео

Положи сжатый файл:

```
assets/videos/hero.mp4
```

До загрузки показывается постер `assets/images/hero/poster.jpg`.

Рекомендации: MP4, H.264, **до 40 МБ**, без звука, 1080p или 720p.

## Favicon

- `favicon-light.svg` — светлая тема браузера
- `favicon-dark.svg` — тёмная тема

Из папки «Сайт Культура Путешествий» на Desktop.

## Логотипы

- `logo-white.svg` / `logo-master.svg` — на тёмном фоне (header)
- `logo-black.svg` — на светлом фоне
