# Видео

## Hero (главная)

Положи сжатый файл сюда:

```
assets/videos/hero.mp4
```

**Требования для GitHub:**
- размер **до 100 МБ** (лучше 15–40 МБ)
- формат MP4 (H.264)
- без звука — OK, если на сайте mute

После того как файл на месте — переключим блок `hero-video` с Kinescope iframe на локальный `<video>`.

## Другие видео

```
assets/videos/hotels/   — ролики отелей в модалке
assets/videos/cases/    — опционально, для кейсов
```

Формат: MP4. Имена латиницей: `maldives-teaser.mp4`
